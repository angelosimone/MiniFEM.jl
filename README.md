# MiniFEM.jl — a pedagogical finite element code

MiniFEM.jl is a pedagogical finite element code written in Julia. It is designed to guide students through a progressive introduction to the finite element method.

The code follows the step-by-step development of a small FEM implementation, starting from explicit scripts that mirror hand calculations, moving gradually toward more structured implementations, and eventually connecting with established Julia FEM libraries such as Ferrite.jl.
